Abrí este proyecto con un servidor local

El cotizador carga su base de datos desde archivos .json usando fetch(). Los navegadores bloquean esas peticiones cuando la página se abre con doble clic (protocolo file://), así que el simulador no puede iniciar.

Para verlo funcionando, elegí una opción:

  • En VS Code: clic derecho sobre index.html y elegí Open with Live Server.
  • Desde la terminal, parado en la carpeta del proyecto: python -m http.server 5500 y entrá a http://localhost:5500.
